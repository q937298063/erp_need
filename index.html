5.1.3 业务流程

[销售订单/手工] → [创建生产订单] → [选BOM流水线] → [添加多条产品明细] → [下达生产] → [生产报工+质检] → [成品入库]
  • 创建生产订单：系统管理员在 Windows 端，选择 BOM，添加多条产品明细，保存即生效。
  • 生产报工与质检：车间操作工在 Android App 上报工，填入完工件数、每件只数、零头只数、不合格只数、不合格原因。提交后明细状态更新为“已完工”。
  • 成品入库：仓管员将合格品入库，模具状态释放。

5.2 库存管理

5.2.1 核心原则

  • 数量管理 + 批次管理：所有物料入库时必须指定批次号，出库按批次扣减。
  • 成本核算：移动加权平均法，每次入库后实时重算该物料的平均成本，出库时按当前平均成本计价。
  • 库存变动：所有出入库单据提交即生效，立即更新库存，无需审核。

5.2.3 移动加权平均算法

新平均成本 = (入库前库存数量 × 入库前平均成本 + 本次入库数量 × 本次入库单价) ÷ (入库前库存数量 + 本次入库数量)

采购入库、生产成品入库时触发重算；出库时直接取当前平均成本，不重算。

5.2.4 业务操作汇总

操作操作人效果
采购入库仓管员增加批次库存 → 重算成本
销售出库仓管员扣减批次库存（按批次先进先出或手动指定）
生产领料出库车间操作工扣减原料批次库存
生产成品入库仓管员增加成品批次库存 → 重算成本
库存盘点仓管员生成盘盈/盘亏单，调整库存
